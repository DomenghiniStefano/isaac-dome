# catalog — plan B (prepares M2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** after this plan, every static datum that can be derived from the game files is normalized in `catalog`: item quality and tags, appearance pools, achievements with their unlock condition, challenges, bosses, DLC of origin — and a test cross-checks the catalog against the save.

**Architecture:** four new per-source modules (`metadata.rs`, `achievements.rs`, `itempools.rs`, `challenges.rs`, `bossportraits.rs`) on top of the single reader `xml.rs`, composed by `Catalog::build`, which now **derives the paths from `SOURCES`** instead of repeating them. The model grows with `Achievement`, `Challenge`, `Boss`, `Pool`; `Item` gains `quality`/`tags` (from `items_metadata.xml`), `pools` and `origin`. No I/O, no change to the `catalog` ↔ `unpack` boundary; `ipc` and `app` are untouched (the Unlock view-models arrive with the M2 contracts).

**Tech Stack:** Rust 2021, `quick-xml = "0.42"`, `serde`; `unpack` and `core-save` only in `[dev-dependencies]`.

**Spec:** `docs/superpowers/specs/2026-09-03-catalog-design.md` (updated on 2026-09-04 with the measurements of plan B's sources — table "The sources" and "Shapes the parser must handle").

## Global Constraints

- No game assets in the repo: test fixtures are hand-written fragments.
- No counts hard-coded in the code; real-data tests pin the numbers as fixtures of a known era (Repentance+, measured on 2026-09-04) with the date in a comment. **If a real-data test fails, the first suspect is the code, not the number**: investigate and report, don't adjust the value.
- Degrade, never fail: no `panic!`/`unwrap()`/`expect()` outside tests on data read from disk. A missing or malformed file → diagnostic, the rest still builds.
- Pure crate: `catalog` has no `unpack`, `core-save`, Tauri or filesystem in `[dependencies]`.
- Exhaustiveness: no `_ =>` on our own enums (allowed on `&str`/`u32`, commented). No new `#[allow]`.
- Before declaring a task done: `cargo test --workspace`, `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`. Real-data tests are run with `cargo test -p catalog --test real_data -- --nocapture` and must show no `skip:` lines on this machine.
- Commit: prefix `catalog:` (or `docs:`), messages in English, **no** `Co-Authored-By` trailer or references to Claude. No push from the tasks.
- Measured numbers (source: spec, section "The sources"): `items_metadata.xml` 721 `<item>` + 188 `<trinket>`, `quality` −1..=4 (−1:2, 0:239, 1:201, 2:251, 3:185, 4:40); `achievements.xml` 637 with ids 1..=637, 283 with a comment; `itempools.xml` 31 pools, 2,058 entries, 26 items in no pool; `challenges.xml` 45 with plural `achievements` (34 with at least one, 13 with more than one); `bossportraits.xml` 103, `achievement` on 27, *The Beast* and *Cadavra* have no portrait in the archives.

```rust
/// The sources, by logical path. Public: callers and tests know what will be asked for.
pub const SOURCES: [(&str, Source); 9] = [
    ("items.xml", Source::Items),
    ("items_metadata.xml", Source::Metadata),
    ("stringtable.sta", Source::Strings),
    ("players.xml", Source::Players),
    ("gfx/ui/coop menu.anm2", Source::CoopMenuAnm2),
    ("achievements.xml", Source::Achievements),
    ("itempools.xml", Source::ItemPools),
    ("challenges.xml", Source::Challenges),
    ("bossportraits.xml", Source::BossPortraits),
];

/// A source's logical path: `build` goes through here, so SOURCES stays the only list.
fn path_of(source: Source) -> &'static str {
    // An exhaustive match: a new source without a path doesn't compile.
    SOURCES
        .iter()
        .find(|(_, s)| *s == source)
        .map(|(p, _)| *p)
        .unwrap_or_else(|| match source {
            Source::Items
            | Source::Metadata
            | Source::Strings
            | Source::Players
            | Source::CoopMenuAnm2
            | Source::Achievements
            | Source::ItemPools
            | Source::Challenges
            | Source::BossPortraits => "",
        })
}
```

The `unwrap_or_else` branch of `path_of` is unreachable by construction (every variant is in `SOURCES`) but it's an exhaustive `match`, not an `unwrap`: if someone adds a `Source` without adding it to `SOURCES`, the build breaks right there. `lib.rs`: `pub use ids::{AchievementId, BossId, ChallengeId, CharacterId, ItemId};`.

```rust
//! `items_metadata.xml`: quality and tags. They aren't in `items.xml` (0 occurrences in the
//! Repentance file): they're here, one row per item, `<item id>` for passives/actives/familiars
//! and `<trinket id>` for the trinkets. The file doesn't distinguish passive, active and familiar:
//! the key for the `<item>`s is `ItemKind::Passive`, and whoever looks for an active or a familiar
//! has to look it up with that one.

use std::collections::BTreeMap;

use crate::diagnostics::{Diagnostic, SkipReason, Source};
use crate::ids::ItemId;
use crate::items::ItemKind;
use crate::xml::{elements, Element};

#[derive(Debug, Clone, PartialEq, Eq, Default)]
pub struct Metadata {
    /// -1..=4 in the real file; `None` if the attribute is missing.
    pub quality: Option<i8>,
    pub tags: Vec<String>,
}

pub fn parse(bytes: &[u8], diagnostics: &mut Vec<Diagnostic>) -> BTreeMap<(ItemKind, ItemId), Metadata> {
    let els = match elements(bytes) {
        Ok(els) => els,
        Err(_) => {
            diagnostics.push(Diagnostic::SourceUnreadable { source: Source::Metadata });
            return BTreeMap::new();
        }
    };
    let mut out = BTreeMap::new();
    for e in &els {
        let kind = match e.name.as_str() {
            "item" => ItemKind::Passive,
            "trinket" => ItemKind::Trinket,
            _ => continue, // allowed: a tag name is an open string
        };
        let Some(raw_id) = e.attr("id") else {
            diagnostics.push(skipped(None, SkipReason::MissingId));
            continue;
        };
        let Ok(id) = raw_id.parse::<u32>() else {
            diagnostics.push(skipped(None, SkipReason::MalformedId));
            continue;
        };
        out.insert((kind, ItemId(id)), metadata_of(e));
    }
    out
}

fn metadata_of(e: &Element) -> Metadata {
    Metadata {
        quality: e.attr("quality").and_then(|q| q.parse().ok()),
        tags: e
            .attr("tags")
            .map(|t| t.split_whitespace().map(str::to_string).collect())
            .unwrap_or_default(),
    }
}

fn skipped(id: Option<u32>, reason: SkipReason) -> Diagnostic {
    Diagnostic::ElementSkipped { source: Source::Metadata, id, reason }
}
```

```rust
//! `achievements.xml`: 637 entries with literal English text (two quote styles, which
//! quick-xml normalizes) and, for 283 of them, the unlock condition in the XML comment
//! that precedes the element. The condition is data: it's kept raw, and it's the graph (M2)
//! that interprets it, not this crate.

use crate::diagnostics::{Diagnostic, SkipReason, Source};
use crate::ids::AchievementId;
use crate::items::normalize_root;
use crate::sprite::SpriteRef;
use crate::xml::{elements, Element};

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Achievement {
    pub id: AchievementId,
    /// English literal, e.g. `You unlocked "Magdalene"`. It is not a key.
    pub text: String,
    /// The XML comment right before the element, if there is one.
    pub unlock_condition: Option<String>,
    pub sprite: SpriteRef,
}

pub fn parse(bytes: &[u8], diagnostics: &mut Vec<Diagnostic>) -> Vec<Achievement> {
    let els = match elements(bytes) {
        Ok(els) => els,
        Err(_) => {
            diagnostics.push(Diagnostic::SourceUnreadable { source: Source::Achievements });
            return Vec::new();
        }
    };
    let gfxroot = els
        .iter()
        .find(|e| e.name == "achievements")
        .and_then(|e| e.attr("gfxroot"))
        .map(normalize_root)
        .filter(|r| !r.is_empty())
        .unwrap_or_else(|| "gfx/ui/achievement".to_string());

    els.iter()
        .filter(|e| e.name == "achievement")
        .filter_map(|e| achievement_from(e, &gfxroot, diagnostics))
        .collect()
}

fn achievement_from(e: &Element, gfxroot: &str, d: &mut Vec<Diagnostic>) -> Option<Achievement> {
    let skip = |id: Option<u32>, reason: SkipReason, d: &mut Vec<Diagnostic>| {
        d.push(Diagnostic::ElementSkipped { source: Source::Achievements, id, reason });
        None
    };
    let Some(raw_id) = e.attr("id") else { return skip(None, SkipReason::MissingId, d) };
    let Ok(id) = raw_id.parse::<u32>() else { return skip(None, SkipReason::MalformedId, d) };
    let Some(gfx) = e.attr("gfx") else { return skip(Some(id), SkipReason::MissingSprite, d) };

    Some(Achievement {
        id: AchievementId(id),
        text: e.attr("text").unwrap_or("").to_string(),
        unlock_condition: e.comment_before.clone(),
        sprite: SpriteRef::whole(format!("{gfxroot}/{gfx}")),
    })
}
```

//! `itempools.xml`: which pool each item appears in and with what weight. 31 pools in the
//! Repentance file, 2,058 entries; every `Id` exists in `items.xml`, and 26 items are in
//! no pool at all (that's a fact, not a defect).

use crate::diagnostics::{Diagnostic, SkipReason, Source};
use crate::ids::ItemId;
use crate::strings::children_named;
use crate::xml::{elements, Element};

#[derive(Debug, Clone, PartialEq)]
pub struct PoolEntry {
    pub item: ItemId,
    pub weight: f32,
    pub decrease_by: f32,
    pub remove_on: f32,
}

#[derive(Debug, Clone, PartialEq)]
pub struct Pool {
    pub name: String,
    pub entries: Vec<PoolEntry>,
}

/// An item's membership in a pool, seen from the item.
#[derive(Debug, Clone, PartialEq)]
pub struct PoolMembership {
    pub pool: String,
    pub weight: f32,
}

pub fn parse(bytes: &[u8], diagnostics: &mut Vec<Diagnostic>) -> Vec<Pool> {
    let els = match elements(bytes) {
        Ok(els) => els,
        Err(_) => {
            diagnostics.push(Diagnostic::SourceUnreadable { source: Source::ItemPools });
            return Vec::new();
        }
    };
    let mut pools = Vec::new();
    for (i, e) in els.iter().enumerate() {
        if e.name != "Pool" {
            continue;
        }
        let Some(name) = e.attr("Name") else {
            diagnostics.push(skipped(None, SkipReason::MissingName));
            continue;
        };
        let entries = children_named(&els, i, "Item")
            .into_iter()
            .filter_map(|item| entry_from(item, diagnostics))
            .collect();
        pools.push(Pool { name: name.to_string(), entries });
    }
    pools
}

fn entry_from(e: &Element, d: &mut Vec<Diagnostic>) -> Option<PoolEntry> {
    let Some(raw_id) = e.attr("Id") else {
        d.push(skipped(None, SkipReason::MissingId));
        return None;
    };
    let Ok(id) = raw_id.parse::<u32>() else {
        d.push(skipped(None, SkipReason::MalformedId));
        return None;
    };
    let num = |name: &str, default: f32| e.attr(name).and_then(|v| v.parse().ok()).unwrap_or(default);
    Some(PoolEntry {
        item: ItemId(id),
        weight: num("Weight", 1.0),
        decrease_by: num("DecreaseBy", 1.0),
        remove_on: num("RemoveOn", 0.1),
    })
}

fn skipped(id: Option<u32>, reason: SkipReason) -> Diagnostic {
    Diagnostic::ElementSkipped { source: Source::ItemPools, id, reason }
}

//! `challenges.xml`: 45 challenges with a literal name. The unlock link here is **plural**
//! (`achievements="42,34,53"`): a list, not an id.

use crate::diagnostics::{Diagnostic, SkipReason, Source};
use crate::ids::{AchievementId, ChallengeId, ItemId};
use crate::xml::{elements, Element};

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Challenge {
    pub id: ChallengeId,
    pub name: String,
    pub starting_items: Vec<ItemId>,
    pub unlocked_by: Vec<AchievementId>,
}

pub fn parse(bytes: &[u8], diagnostics: &mut Vec<Diagnostic>) -> Vec<Challenge> {
    let els = match elements(bytes) {
        Ok(els) => els,
        Err(_) => {
            diagnostics.push(Diagnostic::SourceUnreadable { source: Source::Challenges });
            return Vec::new();
        }
    };
    els.iter()
        .filter(|e| e.name == "challenge")
        .filter_map(|e| challenge_from(e, diagnostics))
        .collect()
}

fn challenge_from(e: &Element, d: &mut Vec<Diagnostic>) -> Option<Challenge> {
    let skip = |id: Option<u32>, reason: SkipReason, d: &mut Vec<Diagnostic>| {
        d.push(Diagnostic::ElementSkipped { source: Source::Challenges, id, reason });
        None
    };
    let Some(raw_id) = e.attr("id") else { return skip(None, SkipReason::MissingId, d) };
    let Ok(id) = raw_id.parse::<u32>() else { return skip(None, SkipReason::MalformedId, d) };
    let Some(name) = e.attr("name") else { return skip(Some(id), SkipReason::MissingName, d) };
    let Some(items) = id_list(e.attr("startingitems").unwrap_or("")) else {
        return skip(Some(id), SkipReason::MalformedList, d);
    };
    let Some(achievements) = id_list(e.attr("achievements").unwrap_or("")) else {
        return skip(Some(id), SkipReason::MalformedList, d);
    };
    Some(Challenge {
        id: ChallengeId(id),
        name: name.to_string(),
        starting_items: items.into_iter().map(ItemId).collect(),
        unlocked_by: achievements.into_iter().map(AchievementId).collect(),
    })
}

/// `"1,2,3"` -> `[1,2,3]`; `""` -> `[]`; a non-numeric element -> `None`.
pub(crate) fn id_list(raw: &str) -> Option<Vec<u32>> {
    raw.split(',')
        .map(str::trim)
        .filter(|s| !s.is_empty())
        .map(|s| s.parse::<u32>().ok())
        .collect()
}

//! The DLC that introduced an item. It isn't in the XML: it's derived from id ranges,
//! which are a stable historical fact (every DLC appended its own items at the end).
//! The thresholds are declared here, with the boundary cases pinned by tests; past the last
//! known id the answer is `None`, not a guess: a future patch will show up in the real
//! test that compares against `items.xml`.

use serde::Serialize;

use crate::ids::ItemId;
use crate::items::ItemKind;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize)]
#[serde(rename_all = "camelCase")]
pub enum Edition {
    Rebirth,
    Afterbirth,
    AfterbirthPlus,
    Repentance,
}

/// (last id included, edition) for the collectibles. Verified on 2026-09-04.
const COLLECTIBLES: [(u32, Edition); 4] = [
    (341, Edition::Rebirth),
    (440, Edition::Afterbirth),
    (552, Edition::AfterbirthPlus),
    (732, Edition::Repentance),
];

/// (last id included, edition) for the trinkets. Verified on 2026-09-04.
const TRINKETS: [(u32, Edition); 4] = [
    (61, Edition::Rebirth),
    (89, Edition::Afterbirth),
    (128, Edition::AfterbirthPlus),
    (189, Edition::Repentance),
];

pub fn edition_of(kind: ItemKind, id: ItemId) -> Option<Edition> {
    if id.0 == 0 {
        return None;
    }
    let table: &[(u32, Edition)] = match kind {
        ItemKind::Passive | ItemKind::Active | ItemKind::Familiar => &COLLECTIBLES,

}
