# catalog — plan A (closes M1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the `catalog` crate reads `items.xml`, `stringtable.sta`, `players.xml`, and `coop menu.anm2` into a model keyed by id with real names, and the verification screen shows names next to the sprites instead of keys.

**Architecture:** pure crate `crates/catalog`: `Catalog::build(read)` asks a closure for the bytes of each source and composes the per-source parsers (`strings`, `items`, `players`, `heads`), all on top of a single reader `xml.rs` over `quick-xml`. The app builds the catalog **once** in Tauri-managed state; `ipc` maps it into a view-model and drops `catalog_peek`.

**Tech Stack:** Rust 2021, `quick-xml = "0.42"`, `serde`; `unpack::ResourceSet` only in the app and as a dev-dependency in the real-data tests; Tauri 2 managed state; Vue 3 / TypeScript for the screen.

**Spec:** `docs/superpowers/specs/2026-09-03-catalog-design.md`

## Global Constraints

- No game assets in the repo: test fixtures are hand-written fragments.
- No counts hard-coded in the code; real-data tests pin the numbers as known-era fixtures (Repentance+, 2026-09-03) and say so in a comment.
- Degrade, never fail: no `panic!`/`unwrap()`/`expect()` outside tests on data read from disk. A missing or malformed file → diagnostic, the rest still builds.
- Pure crate: `catalog` has no dependency on `unpack`, Tauri, or the filesystem in `[dependencies]` (`unpack` is allowed in `[dev-dependencies]`).
- IPC boundary: every struct `#[serde(rename_all = "camelCase")]`; tagged enums `#[serde(tag = "kind", rename_all = "camelCase", rename_all_fields = "camelCase")]` with struct variants, never newtype; never `format!("{:?}")` across the boundary; the JSON shape pinned by tests.
- Exhaustiveness: no `_ =>` on closed enums.
- Before declaring a task done: `cargo test --workspace`, `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`; for the UI `pnpm typecheck`, `pnpm lint`, `pnpm scan`, `pnpm format:check` from the root.
- Commit: prefix `catalog:` / `ipc:` / `app:` / `ui:` / `docs:`, messages in Italian, **no** `Co-Authored-By` trailer nor references to Claude.
- Real-data tests read `samples/packed` (a junction to the game's `resources/packed` folder) and **skip, saying so**, if it's missing.

//! Il catalogo: costruzione e accesso. La logica di lettura sta nei moduli per sorgente.

use std::collections::BTreeMap;

use crate::diagnostics::{Diagnostic, Source};
use crate::ids::{CharacterId, ItemId};

/// Le sorgenti, per path logico. Pubblica: chi chiama e i test sanno cosa verra' chiesto.
pub const SOURCES: [(&str, Source); 4] = [
    ("items.xml", Source::Items),
    ("stringtable.sta", Source::Strings),
    ("players.xml", Source::Players),
    ("gfx/ui/coop menu.anm2", Source::CoopMenuAnm2),
];

/// Segnaposto dei tipi che i task successivi definiscono davvero.
pub struct Item {
    pub id: ItemId,
}
pub struct Character {
    pub id: CharacterId,
}

pub struct Catalog {
    items: BTreeMap<ItemId, Item>,
    characters: BTreeMap<CharacterId, Character>,
    diagnostics: Vec<Diagnostic>,
}

impl Catalog {
    /// Costruisce il catalogo chiedendo i byte di ogni sorgente a `read`.
    /// Non fallisce mai: cio' che manca svuota la sua parte e finisce in `diagnostics`.
    pub fn build(mut read: impl FnMut(&str) -> Option<Vec<u8>>) -> Catalog {
        let mut diagnostics = Vec::new();
        for (path, source) in SOURCES {
            if read(path).is_none() {
                diagnostics.push(Diagnostic::SourceMissing { source });
            }
        }
        Catalog {
            items: BTreeMap::new(),
            characters: BTreeMap::new(),
            diagnostics,
        }
    }

    pub fn items(&self) -> impl Iterator<Item = &Item> {
        self.items.values()
    }

    pub fn characters(&self) -> impl Iterator<Item = &Character> {
        self.characters.values()
    }

    pub fn diagnostics(&self) -> &[Diagnostic] {
        &self.diagnostics
    }
}

//! L'unico strato su quick-xml. I moduli per sorgente lavorano su `Element` e non
//! toccano la libreria: se un giorno cambia, cambia questo file e basta.

use quick_xml::events::Event;
use quick_xml::Reader;

/// Un elemento del documento, in ordine di apertura.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Element {
    pub name: String,
    pub attrs: Vec<(String, String)>,
    /// Il testo diretto dell'elemento, concatenato e senza spazi ai bordi.
    pub text: String,
    /// L'ultimo commento incontrato prima dell'apertura, se nessun elemento lo ha gia' preso.
    pub comment_before: Option<String>,
    /// 0 per la radice.
    pub depth: usize,
}

impl Element {
    pub fn attr(&self, name: &str) -> Option<&str> {
        self.attrs
            .iter()
            .find(|(k, _)| k == name)
            .map(|(_, v)| v.as_str())
    }
}

/// Documento che quick-xml non accetta. Senza dettagli: oltre il confine viaggia solo
/// `Diagnostic::SourceUnreadable`, e un messaggio conterrebbe frammenti del file.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct XmlError;

/// Tutti gli elementi del documento, in ordine di apertura, con testo e commento.
pub fn elements(bytes: &[u8]) -> Result<Vec<Element>, XmlError> {
    let mut reader = Reader::from_reader(bytes);
    reader.config_mut().trim_text(true);

    let mut out: Vec<Element> = Vec::new();
    let mut open: Vec<usize> = Vec::new(); // indici in `out` degli elementi aperti
    let mut pending_comment: Option<String> = None;
    let mut buf = Vec::new();

    loop {
        let event = reader.read_event_into(&mut buf).map_err(|_| XmlError)?;
        match event {
            Event::Start(e) | Event::Empty(e) => {
                let is_empty = matches!(event_kind(&event), Kind::Empty);
                let name = String::from_utf8_lossy(e.local_name().as_ref()).into_owned();
                let mut attrs = Vec::new();
                for a in e.attributes() {
                    let a = a.map_err(|_| XmlError)?;
                    let key = String::from_utf8_lossy(a.key.local_name().as_ref()).into_owned();
                    let value = a.unescape_value().map_err(|_| XmlError)?.into_owned();
                    attrs.push((key, value));
                }
                out.push(Element {
                    name,
                    attrs,
                    text: String::new(),
                    comment_before: pending_comment.take(),
                    depth: open.len(),
                });
                if !is_empty {
                    open.push(out.len() - 1);
                }
            }
            Event::End(_) => {
                open.pop();
            }
            Event::Text(t) => {
                if let Some(&i) = open.last() {
                    let s = t.unescape().map_err(|_| XmlError)?;
                    out[i].text.push_str(s.trim());
                }
            }
            Event::Comment(c) => {
                let s = c.unescape().map_err(|_| XmlError)?;
                pending_comment = Some(s.trim().to_string());
            }
            Event::Eof => break,
            Event::CData(_) | Event::Decl(_) | Event::PI(_) | Event::DocType(_) => {}
        }
        buf.clear();
    }
    if !open.is_empty() {
        return Err(XmlError); // elementi mai chiusi: documento troncato
    }
    Ok(out)
}

enum Kind {
    Start,
    Empty,
}

fn event_kind(e: &Event<'_>) -> Kind {
    match e {
        Event::Empty(_) => Kind::Empty,
        _ => Kind::Start,
    }
}
```

Note for whoever implements this: the `match` on `Event::Start(e) | Event::Empty(e)` binds
`e` and then asks for the type again with `event_kind`; if the compiler complains about the
borrow of `event` inside the arm, rewrite it as two separate arms that call a function
`push_element(&mut out, &mut open, &mut pending_comment, &e, is_empty)`. The `_ =>` in
`event_kind` is allowed: `Event` is an **external** enum, not ours.

//! Una chiave di localizzazione o un testo letterale, e le lingue della stringtable.

use serde::Serialize;

/// Cosa dichiara un attributo `name`/`description`: nei file DLC una chiave
/// (`#THE_SAD_ONION_NAME`), nel base un nome letterale. Si conserva com'e'.
#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
#[serde(tag = "kind", rename_all = "camelCase", rename_all_fields = "camelCase")]
pub enum Text {
    Key { key: String },
    Literal { text: String },
}

impl Text {
    pub fn from_attr(value: &str) -> Text {
        match value.strip_prefix('#') {
            Some(key) => Text::Key { key: key.to_string() },
            None => Text::Literal { text: value.to_string() },
        }
    }
}

/// Le lingue che la stringtable del gioco dichiara. Niente italiano: non c'e'.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize)]
#[serde(rename_all = "camelCase")]
pub enum Language {
    English,
    Japanese,
    Korean,
    ChineseSimplified,
    Russian,
    German,
    Spanish,
    French,
}

impl Language {
    pub const ALL: [Language; 8] = [
        Language::English,
        Language::Japanese,
        Language::Korean,
        Language::ChineseSimplified,
        Language::Russian,
        Language::German,
        Language::Spanish,
        Language::French,
    ];

    /// Dal `name` di `<language>`. Una lingua nuova torna `None` e chi legge lo diagnostica.
    pub fn from_name(name: &str) -> Option<Language> {
        match name {
            "English" => Some(Language::English),
            "Japanese" => Some(Language::Japanese),
            "Korean" => Some(Language::Korean),
            "Chinese (Simple)" => Some(Language::ChineseSimplified),
            "Russian" => Some(Language::Russian),

            "Spanish" => Some(Language::Spanish),
            "French" => Some(Language::French),
            _ => None, // ammesso: l'input e' una stringa aperta, non un enum nostro
        }
    }
}

use crate::diagnostics::{Diagnostic, Source};
use crate::text::Language;
use crate::xml::{elements, Element};

pub struct Strings {
    /// Le lingue nell'ordine degli indici dichiarati, saltate quelle sconosciute.
    languages: Vec<Language>,
    /// chiave -> testi, allineati a `languages` (`None` dove la chiave ne ha meno).
    texts: HashMap<String, Vec<Option<String>>>,
}

impl Strings {
    pub fn parse(bytes: &[u8], diagnostics: &mut Vec<Diagnostic>) -> Option<Strings> {
        let els = match elements(bytes) {
            Ok(els) => els,
            Err(_) => {
                diagnostics.push(Diagnostic::SourceUnreadable { source: Source::Strings });
                return None;
            }
        };

        // Indice dichiarato -> lingua. L'indice 0 e' "Key", non una lingua.
        let mut by_index: Vec<(usize, Option<Language>)> = Vec::new();
        for e in els.iter().filter(|e| e.name == "language") {
            let (Some(index), Some(name)) = (e.attr("index"), e.attr("name")) else { continue };
            let Ok(index) = index.parse::<usize>() else { continue };
            if index == 0 {
                continue;
            }
            let lang = Language::from_name(name);
            if lang.is_none() {
                diagnostics.push(Diagnostic::UnknownLanguage { name: name.to_string() });
            }
            by_index.push((index, lang));
        }
        by_index.sort_by_key(|(i, _)| *i);
        // Posizione dello <string> n-esimo -> lingua (o None se sconosciuta).
        let slots: Vec<Option<Language>> = by_index.iter().map(|(_, l)| *l).collect();
        let languages: Vec<Language> = slots.iter().flatten().copied().collect();

        let mut texts = HashMap::new();
        let mut i = 0;
        while i < els.len() {
            if els[i].name == "key" {
                let Some(key) = els[i].attr("name") else {
                    i += 1;
                    continue;
                };
                let strings = children_named(&els, i, "string");
                let mut row = vec![None; languages.len()];
                for (n, s) in strings.iter().enumerate() {
                    // Lo <string> n-esimo appartiene alla lingua di indice n+1.
                    let Some(Some(lang)) = slots.get(n) else { continue };
                    let pos = languages.iter().position(|l| l == lang).unwrap_or(0);
                    row[pos] = Some(s.text.clone());
                }
                texts.insert(key.to_string(), row);
            }
            i += 1;
        }
        Some(Strings { languages, texts })
    }

    pub fn get(&self, key: &str, lang: Language) -> Option<&str> {
        let pos = self.languages.iter().position(|l| *l == lang)?;
        self.texts.get(key)?.get(pos)?.as_deref()
    }

    pub fn len(&self) -> usize {
        self.texts.len()
    }

    pub fn is_empty(&self) -> bool {
        self.texts.is_empty()
    }

    pub fn languages(&self) -> &[Language] {
        &self.languages
    }
}

/// I figli diretti dell'elemento `parent` con quel nome: quelli che seguono a profondita' +1
/// fino al prossimo elemento a profondita' <= quella del padre.
pub(crate) fn children_named<'a>(els: &'a [Element], parent: usize, name: &str) -> Vec<&'a Element> {
    let depth = els[parent].depth;
    els[parent + 1..]
        .iter()
        .take_while(|e| e.depth > depth)
        .filter(|e| e.depth == depth + 1 && e.name == name)
        .collect()
}
```

The `unwrap_or(0)` on `position` can never trigger (the language comes from `languages` itself); it stays so as not to write an `unwrap` outside the tests. `is_empty` is there because clippy demands it alongside `len`.

//! `items.xml`: oggetti, trinket e familiari, con il path dello sprite gia' composto.

use serde::Serialize;

use crate::diagnostics::{Diagnostic, SkipReason, Source};
use crate::ids::{AchievementId, ItemId};
use crate::sprite::SpriteRef;
use crate::text::Text;
use crate::xml::{elements, Element};

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize)]
#[serde(rename_all = "camelCase")]
pub enum ItemKind {
    Passive,
    Active,
    Familiar,
    Trinket,
}

impl ItemKind {
    fn from_tag(name: &str) -> Option<ItemKind> {
        match name {
            "passive" => Some(ItemKind::Passive),
            "active" => Some(ItemKind::Active),
            "familiar" => Some(ItemKind::Familiar),
            "trinket" => Some(ItemKind::Trinket),
            _ => None, // ammesso: un nome di tag e' una stringa aperta
        }
    }

    /// La sottocartella sotto `gfxroot`: il gioco la sceglie dal tipo, l'XML non la dice.
    fn folder(self) -> &'static str {
        match self {
            ItemKind::Passive | ItemKind::Active | ItemKind::Familiar => "collectibles",
            ItemKind::Trinket => "trinkets",
        }
    }
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Item {
    pub id: ItemId,
    pub kind: ItemKind,
    pub name: Text,
    pub description: Text,
    pub quality: Option<u8>,
    pub tags: Vec<String>,
    pub sprite: SpriteRef,
    pub unlocked_by: Option<AchievementId>,
}

pub fn parse(bytes: &[u8], diagnostics: &mut Vec<Diagnostic>) -> Vec<Item> {
    let els = match elements(bytes) {
        Ok(els) => els,
        Err(_) => {
            diagnostics.push(Diagnostic::SourceUnreadable { source: Source::Items });
            return Vec::new();
        }
    };
    let gfxroot = els
        .iter()
        .find(|e| e.name == "items")
        .and_then(|e| e.attr("gfxroot"))
        .map(normalize_root)
        .unwrap_or_else(|| "gfx/items".to_string());

    els.iter()
        .filter_map(|e| ItemKind::from_tag(&e.name).map(|k| (e, k)))
        .filter_map(|(e, kind)| item_from(e, kind, &gfxroot, diagnostics))
        .collect()
}

fn item_from(e: &Element, kind: ItemKind, gfxroot: &str, d: &mut Vec<Diagnostic>) -> Option<Item> {
    let skip = |id: Option<u32>, reason: SkipReason, d: &mut Vec<Diagnostic>| {
        d.push(Diagnostic::ElementSkipped { source: Source::Items, id, reason });
        None
    };
    let Some(raw_id) = e.attr("id") else { return skip(None, SkipReason::MissingId, d) };
    let Ok(id) = raw_id.parse::<u32>() else { return skip(None, SkipReason::MalformedId, d) };
    let Some(gfx) = e.attr("gfx") else { return skip(Some(id), SkipReason::MissingSprite, d) };
    let Some(name) = e.attr("name") else { return skip(Some(id), SkipReason::MissingName, d) };

    Some(Item {
        id: ItemId(id),
        kind,
        name: Text::from_attr(name),
        description: Text::from_attr(e.attr("description").unwrap_or("")),
        quality: e.attr("quality").and_then(|q| q.parse().ok()),
        tags: e
            .attr("tags")
            .map(|t| t.split_whitespace().map(str::to_string).collect())
            .unwrap_or_default(),
        sprite: SpriteRef::whole(format!("{gfxroot}/{}/{gfx}", kind.folder())),
        unlocked_by: e.attr("achievement").and_then(|a| a.parse().ok()).map(AchievementId),
    })
}

/// `resources/gfx/items/` o `gfx/items/` -> `gfx/items`: senza radice d'archivio ne' barra finale.
pub(crate) fn normalize_root(root: &str) -> String {
    let r = root.replace('\\', "/");
    let r = r.strip_prefix("resources/").unwrap_or(&r);
    r.trim_matches('/').to_string()
}

        d.push(Diagnostic::ElementSkipped { source: Source::Players, id, reason });
        None
    };

    let Ok(id) = raw_id.parse::<u32>() else { return skip(None, SkipReason::MalformedId, d) };
    let Some(portrait) = e.attr("portrait") else { return skip(Some(id), SkipReason::MissingSprite, d) };
    let Some(name) = e.attr("name") else { return skip(Some(id), SkipReason::MissingName, d) };

    Some(Character {
        id: CharacterId(id),
        name: Text::from_attr(name),
        portrait: SpriteRef::whole(format!("{portraitroot}/{portrait}")),
        head: None,
        tainted: portrait.to_ascii_lowercase().ends_with("_b.png"),
        unlocked_by: e.attr("achievement").and_then(|a| a.parse().ok()).map(AchievementId),
    })
}

//! L'anm2 e' XML: animazione `Main`, layer `Main` (id 0), un `<Frame>` per cella.

use crate::diagnostics::{Diagnostic, Source};
use crate::ids::CharacterId;
use crate::sprite::Rect;
use crate::strings::children_named;
use crate::xml::{elements, Element};

pub const SHEET: &str = "gfx/ui/coop menu.png";

/// I frame del layer 0 dell'animazione `Main`, in ordine; `None` dove manca il ritaglio.
pub fn parse(bytes: &[u8], diagnostics: &mut Vec<Diagnostic>) -> Vec<Option<Rect>> {
    let els = match elements(bytes) {
        Ok(els) => els,
        Err(_) => {
            diagnostics.push(Diagnostic::SourceUnreadable { source: Source::CoopMenuAnm2 });
            return Vec::new();
        }
    };
    let Some(main) = els
        .iter()
        .position(|e| e.name == "Animation" && e.attr("Name") == Some("Main"))
    else {
        return Vec::new();
    };
    let main_depth = els[main].depth;
    // Il primo <LayerAnimation LayerId="0"> dentro l'animazione Main.
    let Some(layer) = els[main + 1..]
        .iter()
        .take_while(|e| e.depth > main_depth)
        .position(|e| e.name == "LayerAnimation" && e.attr("LayerId") == Some("0"))
        .map(|p| main + 1 + p)
    else {
        return Vec::new();
    };
    children_named(&els, layer, "Frame").into_iter().map(rect_of).collect()
}

fn rect_of(e: &Element) -> Option<Rect> {
    let n = |name: &str| e.attr(name).and_then(|v| v.parse::<u32>().ok());
    Some(Rect { x: n("XCrop")?, y: n("YCrop")?, w: n("Width")?, h: n("Height")? })
